# CarMonitor iOS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iPhone app that logs an ELM327 BLE clone to CSV and uploads drives to the CarMonitor HA integration, like the Android app.

**Architecture:** Pure logic in a Swift package `ios/CarMonitorKit` (no UIKit, tested with `swift test` on macOS). A thin SwiftUI app `ios/CarMonitor` adds CoreBluetooth, CoreLocation, Keychain and screens, generated by XcodeGen from `ios/project.yml`. CI builds an unsigned IPA.

**Tech Stack:** Swift 6, SwiftUI, CoreBluetooth, CoreLocation, Foundation (JSONSerialization, URLSession), XcodeGen, GitHub Actions macos runner.

**Spec:** `docs/superpowers/specs/2026-11-26-ios-app-design.md`

## Global Constraints
- iOS 17+, Swift 6, no third-party dependencies.
- Read-only guard identical to `core/.../RequestGuard.kt`; every byte to the adapter goes through `RequestGuard.check`.
- CSV format `ts_ms,key,signal,value,raw`, file `drive-YYYYMMDD-HHMMSS.csv`; webhook JSON as in `docs/wiki/Home-Assistant-Integration.md`.
- Bundled OBDb files referenced from `app/src/main/assets/obdb/SAEJ1979.json` and `app/src/main/assets/overlay/_fixes.json` (not copied).
- Android app behaviour unchanged. README/wiki car-agnostic. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
- Adapter replies split across BLE notifications (prompt `>` arrives in a later packet): reader must buffer until `>`.
- Clone with write-without-response only, or 20-byte MTU: commands longer than 20 bytes must be chunked.
- App killed by iOS mid-drive: CSV must hold whole lines; the next launch uploads the rest (offsets only advance on whole lines).
- No network for a whole drive: rows stay in CSV, uploaded later with real timestamps.
- Adapter answers `?` or `NO DATA` to every request (wrong protocol / ignition off): no crash, status shows it, retries every 10 s.
